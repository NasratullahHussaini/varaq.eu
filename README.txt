# وب‌سایت ورق VARAQ
این نسخه استاتیک وب‌سایت VARAQ با متن‌های بازبینی‌شده به زبان دری افغانستان است.

## فایل‌ها
- `index.html`: صفحه اصلی تیره
- `article.html`: نمونه صفحه مقاله روشن
- `styles.css`: طراحی واکنش‌گرا و رنگ‌های برند
- `script.js`: منوی موبایل
- زبان رابط کاربری و محتوای نمونه: دری افغانستان

## پیش از انتشار
1. متن‌های مقاله را بازبینی و منابع علمی را با پیوند معتبر تکمیل کنید.
2. لینک TikTok را در صورت تغییر username به‌روز کنید.
3. متن‌های صفحه را در صورت نیاز از نظر واژگان و اصطلاحات افغانستان بازبینی کنید.
4. دامنه اختصاصی را به GitHub Pages وصل کنید.
5. در صورت استفاده از Google Fonts، برای بارگذاری فونت به اینترنت نیاز است.

## انتشار روی GitHub Pages
فایل‌ها را در ریشه یک repository قرار دهید. سپس Settings → Pages → Deploy from a branch را انتخاب و شاخه `main` و پوشه `/root` را تنظیم کنید.


بخش تازه: فکاهی غزنیچی
- صفحه مستقل: ghazni-humor.html
- پیوند آن در منوی صفحه اصلی اضافه شده است.
- برای افزودن فکاهی، فایل ghazni-humor.html را باز کنید و کارت نمونه را کاپی کرده، عنوان و متن آن را تغییر بدهید.
- هیچ فکاهی نمونه یا ساختگی در سایت درج نشده است.


ارسال فکاهی بازدیدکنندگان به Discord:
1. در Discord یک کانال خصوصی برای دریافت فکاهی‌ها بسازید.
2. از تنظیمات کانال، Integrations > Webhooks > New Webhook را انتخاب و آدرس Webhook را کاپی کنید.
3. فایل joke-submit.js را باز کنید و مقدار PASTE_YOUR_DISCORD_WEBHOOK_URL_HERE را با آدرس Webhook خود جایگزین کنید.
4. فایل‌ها را همراه هم در هاست آپلود کنید. پیام‌های ارسالی در کانال Discord می‌آیند و باید پیش از نشر دستی بررسی شوند.
نکته امنیتی: در این نسخه آدرس Webhook داخل JavaScript سمت مرورگر قرار می‌گیرد و قابل مشاهده است؛ برای استفاده عمومی و جلوگیری از اسپم، بهتر است آن را پشت یک Cloudflare Worker یا سرور واسطه قرار دهید. اگر Webhook افشا شد، آن را در Discord حذف و دوباره ایجاد کنید.
